# KURO Logi — 홈페이지 (HTML + 순수 CSS)

`kurologi.jp` 홈페이지를 **순수 CSS**로 재구성했습니다. Bootstrap 클래스는 쓰지
않았습니다 — 유틸리티 클래스(`col-lg-4`, `card-body`, `d-flex`, `btn-dark` …) 대신
의미 있는 이름(`col--one-third`, `card__body`, `btn--dark`)을 사용합니다.

**한 페이지, 한 CSS, 데스크톱 전용.** 미디어쿼리 없음.

### 마이페이지 구성

**종합현황에서 나의 정보·나의 사서함 주소를 마이페이지로 옮겼습니다.**
종합현황은 이제 5개 섹션입니다:
요약 탭 · 현황판 · AI 신청서 자동 생성 · 공지/환율/1:1 · 자주하는 질문

마이페이지는 3개 영역입니다:

| 영역 | 내용 |
|---|---|
| 나의 정보 | 6칸 표 — 등급·포인트·친구 추천 포인트·예치금·회원번호·이용실적 |
| 나의 사서함 주소 | 센터 3개 카드 + Copy All |
| 마이페이지 관리 하기 | 관리 메뉴 **3개** |

#### 관리 메뉴 3개와 연결 페이지

| 메뉴 | 연결 페이지 | 화면 |
|---|---|---|
| 계정관리 | `마이페이지/account.html` | 회원정보 수정 |

프라임멤버쉽·쿠폰·포인트·장바구니·고객센터 5개는 요청하신 대로 삭제했습니다.

### 새로 만든 3개 하위 페이지

**계정관리** — 상단 4개 바로가기, 회원 요약 다크 바, "회원정보 수정" 표
(아이디·사서함번호·이름·영문이름·비밀번호·휴대폰·이메일·마지막로그인·
SMS수신동의·개인/사업자), 정보수정/탈퇴하기 버튼

**결제방법** — 비용결제/결제내역 탭, 빈 결제 목록, 안내 문구,
무통장입금/신용카드(토스) 선택, 예치금 전액사용·회원명으로 사용 버튼,
결제금액/쿠폰할인/Total 패널, 결제하기 버튼

**주소관리** — 나의 주소록 제목, 주소검색 줄(이름/주소 선택 + 검색),
새주소추가 버튼, 주소 카드(이름·주소·국가·전화·개인통관부호, 수정/삭제),
페이지 번호

### 주 메뉴를 고치려면

메뉴는 **`index.html` 하나만** 고치면 됩니다. 나머지 25개 페이지는
`tools/sync-nav.mjs` 가 홈페이지 메뉴를 그대로 복사해서 맞춰 줍니다.

```bash
# 1) index.html 의 <nav> 를 수정
# 2) 링크할 페이지가 새로 생겼다면 tools/sync-nav.mjs 의 PAGE_BY_LABEL 에 추가
# 3) 26개 페이지에 반영
node tools/sync-nav.mjs
```

스크립트가 하는 일:

- 홈페이지의 메뉴를 그대로 복사 (메뉴가 페이지마다 달라지는 것을 막음)
- 각 페이지 위치에 맞게 링크 앞에 `../` 를 붙임
- 현재 보고 있는 항목에 `is-current` 표시
- 상단 항목을 누르면 그 항목의 첫 페이지로 이동하게 연결
- 홈페이지 메뉴가 예상(6개 항목)과 다르면 **에러를 내고 멈춤**

## 페이지 구조 — CSS 인라인 (외부 CSS 파일 없음)

**각 HTML이 자기 스타일을 직접 품고 있습니다.** `<link href="...css">` 가 아니라
`<head>` 안의 `<style>` 블록입니다.

- 26개 페이지 모두 **자기 완결형** — HTML 파일 하나만 있으면 화면이 나옵니다
- CSS 경로가 깨져도 스타일이 유지됩니다
- 파일 하나를 다른 곳에 복사해도 그대로 동작합니다

```html
<head>
  ...
  <link href="https://fonts.googleapis.com/css2?family=..." rel="stylesheet">
  <style>
  /* inlined from 종합현황/dashboard.css */
  :root { --teal: #159692; ... }
  ...
  </style>
</head>
```

> **폰트 링크만 외부로 남아 있습니다.** `Noto Sans KR` 과 `Lato` 는 구글이
> 제공하는 웹폰트이고, 이걸 인라인하면 폰트 자체를 파일에 넣어야 해서
> 용량이 크게 늘고 갱신도 안 됩니다.

### 다시 만들기

CSS를 고쳤다면 다시 인라인해야 합니다:

```bash
node tools/inline-css.mjs --check   # 무엇이 바뀔지 먼저 확인
node tools/inline-css.mjs           # 실제 적용
```

이미 인라인된 페이지는 알아서 건너뜁니다. CSS 원본 파일은 그대로 남아 있으니,
수정은 CSS에서 하고 다시 인라인하면 됩니다.

### 색상 바꾸기

색은 `종합현황/dashboard.css` 맨 위 `:root` 에 모여 있습니다 (`--teal`, `--blue`,
`--red`, `--container`, `--gutter` 등).

> ⚠️ 이 파일은 **공통 뼈대(상단바·헤더·페이지 제목·푸터)의 유일한 원본**입니다.
> `tools/lib-chrome.mjs` 등 3개 스크립트가 이 파일을 읽어 모든 페이지의
> 뼈대를 만듭니다. 지우면 페이지를 다시 생성할 수 없습니다.
>
> 나머지 CSS 파일들은 HTML 안으로 인라인된 뒤 삭제했습니다.

### 점검 도구

```bash
node tools/audit-pages.mjs     # 페이지별 인라인 CSS 가 온전한지
node tools/check-classes.mjs   # 마크업 클래스에 CSS 규칙이 다 있는지
node tools/inline-css.mjs --check  # 인라인 안 된 페이지가 있는지
node tools/compare-render.mjs  # figma-export 기준선과 픽셀 비교
```

## 클래스 이름 규칙

BEM 스타일로 통일했습니다. `블록__요소--변형`:

```
card            카드 전체
card__body      카드 안쪽 여백 영역
card--pad       위아래 20px 여백을 더 주는 변형
```

## 색상과 폭

`종합현황/dashboard.css` 맨 위 `:root` 한 곳에 모여 있습니다:

```css
:root {
  --teal:      #159692;   /* 헤더, 기본 버튼 */
  --blue:      #107abd;   /* 링크, 포인트 */
  --red:       #dd4b39;   /* 경고, 강조 */
  --container: 1360px;    /* 전체 폭 */
  --gutter:    15px;      /* 좌우 여백 */
}
```

이 파일의 값을 바꾸면 새로 생성되는 페이지에 반영됩니다. 이미 만들어진
26개 페이지는 각자 `<style>` 안에 색을 복사해 가지고 있으므로, 색을 바꾸려면
해당 페이지의 `<style>` 도 함께 고쳐야 합니다.

## 검증

현재 점검 도구 4개가 모두 통과합니다:

```bash
node tools/audit-pages.mjs      # 페이지별 인라인 CSS 온전성
node tools/check-classes.mjs    # 마크업 클래스 ↔ CSS 규칙 대조
node tools/compare-render.mjs   # figma-export 기준선과 픽셀 비교
node tools/inline-css.mjs --check  # 인라인 안 된 페이지 확인
```

결과:

- 26개 페이지 모두 **외부 CSS 링크 0개**, CSS 인라인 완료
- 마크업이 쓰는 모든 클래스에 CSS 규칙 존재 (규칙 없는 클래스 0개)
- 태그 짝 일치 · 깨진 로컬 경로 **0개**
- 주 메뉴 6개 항목 · 서브메뉴 **6개** · **nav `#` 링크 0개**
- **마이페이지 드롭다운 = 4개 (마이페이지·계정관리·결제방법·주소관리)** — 26개 페이지 전부

색상은 원본 사이트에서 픽셀 단위로 추출해 검증했습니다:

- 홈페이지: 계산된 스타일 **98.9% 일치**
- 서비스안내: 표 머리글 `#f4fafa`, 상단선 `#107976`
- 종합현황: 탭 `#ff7000`/`#6441be`/`#37b149`/`#2e6fe5`
- 구매대행·배송대행: 머리글 `#e4f0f9`, 버튼 `#1e3354`

브라우저에서 렌더링과 마이페이지 드롭다운이 열리는 것까지 확인했습니다.

## 확인하지 못한 것

- **자바스크립트는 홈페이지 탭·팝업만** 동작합니다. 나머지 페이지의
  체크박스·파일 선택·등록 버튼은 겉모양만입니다.
- **320~499px 폭은 확인하지 못했습니다.** 헤드리스 크롬이 최소 500px 이라
  그 아래는 캡처할 수 없었습니다. 데스크톱 전용이라 미디어쿼리도 없습니다.
- **팝업 내부**: 원본 팝업은 이미지 한 장이라 안쪽은 근사치입니다.
- **로그인 후 동작**은 확인할 수 없습니다. 값은 전부 정적입니다.

## 내용 주의

주소·전화번호·계좌·요율·수수료·공지 문구는 **실제 서비스의 값**입니다.
공개하기 전에 본인 내용으로 바꾸세요.

참고한 스크린샷 중 일부는 다른 회사(오마이집, 타배) 화면이라 **구성만 참고**하고
브랜드·메뉴·푸터·로고는 KURO Logi 것으로 바꿨습니다. 타배의 사업자 정보
